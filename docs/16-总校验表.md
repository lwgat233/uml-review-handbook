## 2. 怎么复跑（给人照抄）

```bash
# 工具（本机已就位，不许联网下载）
J=/home/lwgat/tools/jdk-17.0.2/bin/java
U=/vol1/1000/aicache/tools/plantuml.jar
cd /vol1/1000/airesults/uml-复习手册

# ① 语法检查：每个源文件单独跑，必须 rc=0 且不出现 “Some diagram description contains errors”
for f in src/*.puml; do $J -jar $U -checkonly "$f"; echo "$f rc=$?"; done

# ② 出图：一块一张图（每个 svg 里的 <svg 计数应 = 1）
$J -jar $U -tsvg -o ../figures src/*.puml
grep -c "<svg" figures/*.svg

# ③ 闸门：rc=0 ≠ 图对 —— 逐个 svg 查“报错占位图”，必须全 0
grep -c "Cannot find Graphviz\|Syntax Error\|Dot Executable" figures/*.svg

# ④ 数量核对：应当是 14 张
ls figures/*.svg | wc -l
```

**三条硬规矩（踩过的坑，写在证据里）**

1. **一个 `@startuml…@enduml` 只放一张图**（混放时 `-checkonly` 直接 rc=200 报 `Error line N`）。
2. **本机没有 graphviz** ⇒ 类图/用例图/组件图/部署图/对象图/包图/组合结构图/制品图/通信图/交互概览图/**状态机图**/定时图都要在块内加一行 **`!pragma layout smetana`**；
   只有 **时序图 / 活动图**不需要。**状态机图这条最容易漏**（见下）。
3. **`rc=0` 不等于图对**：状态机图漏加 `smetana` 时，`-tsvg` 仍 `rc=0`，但导出物是**一张写着 `Cannot find Graphviz` 的报错占位图**（3.9KB）。
   ⇒ 必须跑第 ③ 步闸门；本轮就是这么抓出来的（修完 18KB）。另外**活动图/定时图里不要用游离 `note`**（会报 `Error line N`），整体说明用 `legend`。
