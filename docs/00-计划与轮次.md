# 00 · 计划与轮次（UML 复习手册）

**依据**：本人 2026-09-26 两句原话 ——「这个 investigator 以后要完成的任务就是编写 UML …… 测试一下，让他测试自己编写的 UML 是不是符合 UML 语法」＋「**都画出来，我把这个基础知识都差不忘了。**」
**用途**：本人自己复习 ⇒ **给人看的材料**（中文、通俗、能"说出来"），不是内部工程文档。
**主题**：UML 2.5 的 **14 种图**（结构类 7 + 行为类 7）。

## 全套共用的一个小例子（开工第一件事：定稿）
建议用 **mark-readnotes 随笔 App**（本人熟：H1 主题 + 五类块（链接/提问/回答/概念/观点）+ 标签文件夹 + 导出 + WebDAV 同步），
好处＝同一套名词能把 14 张图串起来（类/对象/包/组件/部署/组合结构/制品 + 用例/活动/状态机/时序/通信/交互概览/定时）。
**备选**：社媒整理平台（有采集→转文本→归档的流程与飞牛部署面）。**定稿前先问本人一句**（或按女仆建议直接用 mark-readnotes）。

## 每节模板（四样，缺一不算交）
1. **一句话**：这张图讲什么、什么时候用它；
2. **关键元素**：方框/箭头各代表什么（术语中文，英文原词括注）；
3. **最小示例**：用上面那个共用例子；示例文字说明 + 图；
4. **源与校验**：`src/<图名>.puml` + `figures/<图名>.svg` + `evidence/校验-<轮次>.txt`（`-checkonly` 输出与 rc＝0）。

## 分轮（**先出骨架 + 头几张，别一口气写完**）

| 轮 | 内容 | 种数 | 交什么 |
|---|---|---|---|
| **1** | 手册骨架：目录 + 「**选哪种图**」对照表 + 共用例子定稿 + **类图 / 用例图 / 时序图**（最常用三张） | 3 | `docs/01-选哪种图.md`、`docs/02-类图.md`、`docs/03-用例图.md`、`docs/04-时序图.md` + 源/图/校验读数 |
| **2** | 结构类余下：**对象图 / 包图 / 组件图 / 部署图** | 4 | 各自一节 + 四样 |
| **3** | 结构类收尾 + 行为类两张：**组合结构图 / 制品图 / 活动图 / 状态机图** | 4 | 同上 |
| **4** | 行为类余下 + 总自检：**通信图 / 交互概览图 / 定时图** + **全 14 张总校验表** | 3 | 各自一节 + `evidence/校验-总表.txt`（14 张 rc 全 0） |

合起来 = 14 种。**每轮交付后停下等本人看**（他给反馈再继续下一轮）。

## 判据（每轮都按这个验）
- `java -jar plantuml.jar -checkonly src/*.puml` **rc=0、无 error**；`-tsvg` 导出成功（图数 = 本轮种数）；
- 手册里每节**四样齐全**；术语中文；示例与共用例子一致；
- 「选哪种图」对照表覆盖 14 种（想表达什么 → 用哪张）；
- 未验的写「待确认」，**未验 ≠ 通过**；**不改代码**。
